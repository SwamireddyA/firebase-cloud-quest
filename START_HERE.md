# START HERE (4 double-clicks)

1. Double-click  setup_cloud_quest.bat  (once, ~5 min). It builds the project in  ..\cloud_quest_app  .
2. Open the  cloud_quest_app  folder. Double-click  1_start_emulators.bat  and leave that window open.
3. Start your Android emulator. Double-click  2_seed_and_run_app.bat . Use the app, take your screenshots (see README.md table).
4. Close the emulator window from step 2. Double-click  3_run_tests.bat . Output is saved in  evidence\test_output.txt .

Then fill the FILL IN blanks in README.md, write the reflection (REFLECTION_TEMPLATE.md), create a NEW GitHub repo and push.
If anything shows an error, copy the text and send it to Claude.
